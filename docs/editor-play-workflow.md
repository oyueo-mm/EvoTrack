# EvoTrack 편집·플레이 워크플로 개선

2026-10-24. 기존 맵·모델·실험과 IndexedDB 저장소를 보존하는 후속 개편입니다.

## 캔버스와 전역 메뉴

빈 공간의 기본 드래그는 팬입니다. 배치 도구로 누른 뒤 드래그하면 임시 배치를 되돌리고 카메라를 이동합니다. 요소 선택·이동, 회전/크기 핸들, 명시적으로 선택한 지우개 동작은 유지합니다. 도로는 클릭으로 제어점을 추가합니다. Ctrl+왼쪽 세로 드래그는 포인터를 기준으로 지수형 줌이며, 오른쪽/중간 버튼·Space 팬과 휠/핀치도 지원합니다. Shift 또는 직각 스냅 토글로 90° 단위 회전, 선택 요소에 0/90/180/270° 가이드를 표시합니다. Inspector 각도 직접 입력도 유지합니다.

전역 메뉴는 데스크톱에서 64px 미니바와 펼친 메뉴를 전환하며, 너비 192–360px을 드래그 또는 키보드 방향키(16px)로 조정합니다. 너비·접힘 상태는 localStorage에 보관합니다. 좁은 화면과 전체 화면 에디터에서는 overlay drawer로 전환하며 Escape/배경 클릭으로 닫습니다.

## 요소와 환경 버전

Inspector는 벽·이동 장애물·가시·폭탄·점프대·탄성 발판·체크포인트·부활 표식의 실제 동작을 설명합니다. 공통 장애물 도구에는 가시, 폭탄, 이동 장애물이 포함됩니다.

- 점프대: 접촉 시 `launchStrength`(50–1200px/s)로 즉시 발사합니다. `launchAngle`은 요소 회전에 대한 상대 각도이며 기본값은 -90°, 세기는 520입니다.
- 탄성 발판: 접촉 전 법선 방향 입사 속도에 `restitution`(0–2, 기본 0.8)을 곱해 반사합니다. 작은 접촉 속도는 안정적으로 바닥에 머물며, 0은 반발하지 않습니다.
- 폭탄/가시: 접촉 즉시 실패합니다. 폭탄은 빨간 원과 !, 부활 표식은 파란 R로 구분합니다. 이동 장애물의 진폭/주기는 기존 속성 입력을 사용합니다.

새 맵은 환경 v3입니다. v1/v2 맵은 자동 변환하거나 덮어쓰지 않습니다. 기존 맵에서 새 계수/폭탄/부활 표식을 쓰려면 **확장 환경 v3 편집본 만들기**를 선택합니다. 별도 ID로 복제하므로 원본과 기존 모델을 보존합니다. 기존 점프대/탄성 발판의 고정 반발 규칙은 v1/v2에서 유지합니다. 모델은 실제 학습 맵의 환경 버전을 기록하며 환경 버전이 다른 평가는 명확히 거부합니다. 관측/AI 행동 스키마는 변경하지 않습니다.

## 테스트 조작과 진행도

| 입력               | Racing                     | Bounce                          |
| ------------------ | -------------------------- | ------------------------------- |
| A/D 또는 ←/→       | 가속 없는 방향 회전        | 좌우 이동                       |
| W 또는 ↑           | 전진                       | 점프                            |
| S 또는 ↓           | 후진/감속                  | 공중 빠른 하강                  |
| Space              | 추가 가속·최고 속도 부스트 | 수평 공중 제동                  |
| R / 즉시 부활 버튼 | 시작점 복귀                | 마지막 부활 표식, 없으면 시작점 |

테스트 시작 시 캔버스에 키보드 포커스를 줍니다. 실패 후 약 180ms 뒤 자동 재시도하며 테스트 모드를 유지합니다. 성공하면 완주 상태를 보여줍니다. 터치 조작 버튼도 제공합니다. 부활 표식은 비고체이고 보상 게이트가 아닙니다. 학습에서는 실패 에피소드를 종료하므로 테스트 재시도가 학습 보상을 바꾸지 않습니다.

체크포인트는 진행 순서·보상·경로 안내 게이트입니다. 자동 부활 지점으로 사용하지 않습니다. 0개 Racing 맵도 저장·테스트·학습할 수 있고 현대 환경(v2/v3) 진행도는 도로 중심선의 연속 이동 거리와 결승점으로 계산합니다.

## 홈과 학습 중 편집

홈 hero는 실제 Simulator를 캔버스에 재생합니다. 실패 → 재시도 → 완주를 반복하며 동작 예시임을 명시합니다. 학습이 실제로 진행된다는 주장을 하지 않습니다. 일시정지, reduced-motion 기본 정지, 화면 밖/백그라운드 일시정지를 지원합니다.

학습 시작 시 맵을 세션용 스냅샷으로 고정합니다. 학습 중 에디터 진입은 별도 ID의 draft로 분기하며 Worker는 원본으로 계속 실행합니다. 저장 모달의 **다음 세션부터 적용**은 편집본만 저장합니다. **지금 세션 재시작**은 저장된 편집본으로 새 학습을 시작하며 기존 세션의 학습 상태는 이어붙이지 않습니다. 재시작이 필요함을 모달에 설명합니다. 추론 모델과 실험 저장은 편집본이 아닌 실제 세션의 맵·ID·물리 버전을 기록합니다. 이미 저장된 모델/체크포인트는 보존합니다.

미저장 상태는 저장 기준 스냅샷과 비교하며 화면 이탈과 브라우저 새로고침/닫기 전에 경고합니다. 도구 툴팁·단축키와 테스트/리스폰 규칙을 Inspector·상태바에 제공합니다.
