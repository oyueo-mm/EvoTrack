# 맵 편집 작업 공간 개편 — 2026-10-24

## 사용자 경험

- 편집기는 `100dvh` 작업 공간을 사용한다. 전역 메뉴는 접히고, 맵 이름·모드·저장 상태·Undo/Redo·테스트·저장이 상단에 모인다.
- 캔버스 위 플로팅 도구 모음은 화면 폭에 따라 가로로 스크롤된다. 오른쪽 Inspector는 속성·레이어·맵 설정으로 분리했다. 페이지 대신 Inspector 안에서 스크롤한다.
- 태블릿은 Inspector를 접을 수 있고, 모바일은 오버레이 하단 시트로 연다. 캔버스의 터치 입력은 페이지 스크롤과 분리한다.
- 우클릭·가운데 버튼·Space 드래그는 카메라만 움직인다. 선택 도구의 빈 공간 드래그와 손 도구도 유지한다. 우클릭 해제·취소·캡처 손실·창 포커스 손실 때 입력을 종료한다.
- 커서 중심 휠/트랙패드 줌, 터치 핀치, 줌 버튼, 미니맵, 화면 맞춤(`F` 또는 `1`), 선택 요소로 이동을 제공한다. 카메라는 맵별 세션 캐시에 보존한다.
- 도로는 클릭으로 점을 추가하거나 드래그해 그린다. 기본은 기존 도로에 추가하며 옵션에서 새 경로로 교체할 수 있다. 선택 도구로 제어점을 이동한다.
- 곡선 다듬기는 corner cutting 결과를 실제 `road` 좌표에 반영한다. 화면에만 곡선을 그리지 않으므로 기존 Simulator의 충돌 지형과 렌더링이 같은 선분을 사용한다. 시작·끝 좌표를 보존하며 끊어진 경로는 먼저 연결해야 한다.
- 지우개는 반경 미리보기와 드래그 단위 Undo를 지원한다. 숨기거나 잠근 레이어를 보호한다. 겹친 요소는 반복 클릭으로 순환 선택한다.
- 레이어의 표시·잠금은 편집 세션 상태다. 학습 지형과 기존 저장 포맷을 바꾸지 않는다. 테스트 실행에는 숨긴 지형도 포함된다.
- 공통 컬러·입력·버튼·타이포그래피 토큰을 홈, 학습, 비교, 라이브러리에 적용했다. 라이트 테마를 기본으로 제공하고 테마 선택을 저장한다.

## 작업 공간 이전

상단 **데이터 백업 · 이전**에서 전체 JSON 내보내기와 가져오기를 제공한다. 저장하지 않은 편집 내용은 먼저 맵으로 저장해야 한다.

- 기존 v0.1 `{ maps, models, experiments }` 백업을 계속 지원한다. 새 백업은 `format`, `version: 1`, `schemas`를 포함한다.
- 파일의 맵·모델·실험을 전부 검증한 뒤 기존 개수, 파일 개수, 중복 ID, 실제 복원 개수를 표시한다. 중복을 건너뛰거나 파일 내용으로 덮어쓸 수 있다.
- 파일 내부의 중복 ID, 불완전한 스키마, 손상된 모델·실험·맵은 가져오기 전에 거부한다. 모델에 내장된 학습 맵과 정책 스키마도 검증한다.
- 가져오기는 세 object store를 묶은 하나의 IndexedDB readwrite 트랜잭션이다. 쓰기 실패는 전체 롤백한다. 미리보기 이후 다른 탭이나 학습 기록 저장으로 데이터가 바뀌면 다시 검토하도록 중단한다.
- 기존 `evotrack` DB 이름, 버전 1, object store, 맵 버전과 모델 스키마를 유지한다. 저장소를 지우거나 새 DB로 이동하지 않는다.
- 전체 작업 공간 파일 제한은 200 MB, 개별 맵·모델 파일은 기존 20 MB다. 파일에 없는 기존 자료는 삭제하지 않는다.

## 검증

로컬 단위 테스트 42개와 Chromium E2E 15개가 통과했다. TypeScript 검사와 프로덕션 빌드도 통과했다.

| 영역 | 검증 내용 |
| --- | --- |
| 학습 | Racing/Bounce 실행, GA/PPO 단독·동시 Worker 실행, 일시정지/재개, 처리 배속, 세션 분리 |
| 저장 | 맵·모델 새로고침 유지, 추론 모델 내보내기/가져오기, GA/PPO 체크포인트 상태 복원 |
| 평가 | 다른 맵에서 3개 시드로 실제 Worker 평가 |
| 편집 | 도로 생성·폭 변경, 지우개, Undo/Redo, 요소 선택·위치·레이어 잠금 |
| 입력 | 실제 Playwright 우클릭 down→move→up, 캔버스 밖 해제, 창 blur, 가운데 버튼, Space 팬, 커서 중심 줌, 그리기·배치 중 핀치 전환 취소 |
| 이전 | v0.1 호환, 개수·중복 미리보기, skip/overwrite, 세 자료 유형 함께 복원, 손상 파일 전체 거부, 쓰기 실패 롤백, 동시 변경 감지 |
| 반응형 | 1440×900, 1440×720, 1024×600 작업 공간 무스크롤, 390×844 터치·핀치·하단 패널 |

`npm run validate:learning`의 기본 벤치마크에서 Racing GA/PPO와 Bounce GA/PPO 네 경우 모두 평가 보상이 증가했고, 3개 평가 시드의 완주율은 각각 100%였다. Bounce 벤치마크는 기존 검증 스크립트의 평평한 기본 환경이며 모든 장애물 맵의 완주를 의미하지 않는다.

모바일은 Chromium의 모바일·터치 에뮬레이션 및 CDP 터치 이벤트로 검증했다. 실제 휴대폰 하드웨어 검증은 수행하지 않았다.

스크린샷은 `.cache/ui-review/`에 생성한다. 주요 파일:

- `editor-overview-desktop.png`, `editor-desktop-dark.png`
- `editor-mobile.png`, `editor-mobile-inspector.png`
- `home-overview-desktop.png`, `lab-overview-desktop.png`, `maps-overview-desktop.png`

Pages 워크플로는 로컬 대상 테스트와 빌드를 먼저 통과한 뒤 배포하고, 공개 URL을 대상으로 다시 브라우저 테스트한다. 검증 보고서와 UI 스크린샷은 Actions artifact에 보관한다.
