# EvoTrack 학습 성능 개선 실험

이번 버전은 GA와 PPO의 학습 안정성 및 탐색을 개선하기 위한 실험적 변경이다. 기존 지도, 정책 신경망 형태, 환경 보상, 저장된 모델을 변경하지 않는다.

- PPO: Bounce 환경에서는 정책망 Actor와 가치망 Critic의 gradient norm을 각각 0.5 이내로 제한한다. Racing은 첫 비교에서 최고 완주율 하락이 관찰돼 기존 공동 gradient norm 제한을 유지한다. Adam 상태 직렬화 형식은 유지한다.
- GA: Racing은 교차에서 한 은닉 뉴런의 입력 가중치, 편향, 출력 가중치를 같은 부모에서 상속한다. 4세대 이상 최고 보상이 갱신되지 않으면 돌연변이 강도를 점진적으로 늘리고, 8세대 이후에는 약 8% 신규 개체를 마지막 자리에 주입한다. Bounce는 첫 비교에서 일부 완주율 하락이 확인돼 기존 교차 및 변이 전략을 유지한다. 엘리트 및 최상 기록을 보존하고, 체크포인트에는 선택적 stagnantGenerations 필드를 추가한다.
- 검증: scripts/benchmark-learning-v06.ts에서 동일 학습 시드 17/42/89, 평가 시드 101/202/303으로 기존 커밋과 새 커밋을 비교한다. 환경 상호작용 예산은 GA 32,768, PPO 16,384(세대 경계에 따른 약간의 초과 가능). r-straight, r-serpent, b-v5-horizontal을 사용한다. 샘플 수가 적어 전체 환경에서의 유의한 우위를 보장하지 않는다.

최종 성능 판정은 GitHub Actions의 learning-comparison 산출물 및 로그를 기준으로 한다. 측정 결과 없이 성능 향상률을 주장하지 않는다.
