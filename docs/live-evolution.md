# 실시간 다중 개체 진화와 맵 편집 고도화

2026-10-24 · 기준 main `c73d61e6dddc115c1e24305a1dd38ba7b9ac8d91` · 개발 브랜치 `feat/live-population-and-gates`.

## 실제 개체군 시뮬레이션

`GeneticTrainer`는 정책마다 독립적인 `Simulator`와 관측값을 보관한다. `advance()`는 한 물리 스텝마다 아직 종료되지 않은 모든 환경을 같은 `1/60초`만큼 진행한다. 모두 같은 시작 위치·환경 시드에서 출발하지만 정책 가중치와 환경 상태는 독립적이며 개체 간 물리 충돌은 없다.

전원이 완주·충돌·시간 초과로 종료되면 적합도 집계, 엘리트 보존, 토너먼트 선택, 교차·돌연변이 후 다음 세대를 시작한다. 기존 동기식 `run()`은 같은 스텝 엔진을 세대 끝까지 호출하는 벤치마크용 진입점으로 유지한다.

Worker는 요청 배속(0.5–10×)에 따라 물리 스텝을 누적하고 약 12ms 작업 예산마다 제어권을 돌려준다. 화면에는 약 20Hz로 실제 개체 위치·속도·종료 상태·센서값과 최근 48점의 궤적을 보낸다. 물리 timestep과 렌더링은 분리되어 있으며 GPU가 필요하지 않다. 이전 종료 위치를 새 출발 위치로 옮겨 그리거나 대표 정책을 개체 수만큼 복제해 재생하지 않는다.

캔버스는 GA의 실제 Worker 스냅샷을 렌더링한다. PPO 대표 정책 재생은 별도 경로다. 전체·생존·현재 최고 개체 표시, 개체 선택, 선택 개체 추적, 궤적·실제 센서 길이 표시를 지원한다. 최고 개체는 금색, 충돌 개체는 옅은 색, 완주 개체는 초록색으로 구분한다. 차들이 같은 정책 행동으로 겹치는 경우 위치를 인위적으로 벌리지 않는다.

상단 실행 제어에 맵·알고리즘·배속·시작/일시정지/재개·중지 액션을 모았다. 세대·전체/생존/충돌/완주 수·현재 최고/평균 적합도·실제 배속·처리량을 표시한다. 세대별 그래프는 완료된 세대의 측정값만 추가한다. GA와 PPO 동시 실행은 서로 다른 Worker를 유지한다.

## 체크포인트와 보상

도로는 형상만 정의한다. 도로 클릭·드래그·스무딩은 체크포인트를 만들거나 이동하지 않는다. 기존 예제의 조밀한 자동 체크포인트는 명시적인 소수 게이트로 줄였다. 사용자는 게이트를 자유롭게 추가·이동·삭제·복제·재정렬한다. 새 Racing 환경은 게이트가 0개여도 실행할 수 있다.

새 게이트는 `id`, `x/y`, `width`, `angle`, `order`, `directional`을 가진다. 배열 순서를 실제 통과 순서로 사용하고, 저장되는 `order`는 그 인덱스와 일치하도록 관리·검증한다. `angle`은 화살표가 가리키는 전진 법선의 라디안 각도다. 기본값은 방향성 있는 게이트이며 역방향 통과를 인정하지 않는다. 명시적인 `directional:false` 데이터는 양방향 통과를 허용한다.

이전·현재 위치 사이의 선분과 유한 게이트 선분의 교차를 보간한다. 다음 순서의 게이트만 인정하며, 같은 스텝 안에서 여러 게이트를 지나는 경우에도 교차 시각 순서를 유지한다. 측면 접근, 역주행, 먼 게이트 먼저 통과, 종료 뒤 반복 점수 획득은 인정하지 않는다. 위치·폭·회전 편집은 이 판정에 직접 사용된다.

연속 진행도는 도로 중심선의 누적 길이를 추적한다. 실제 이동량에 비례하는 제한된 arc 구간에서만 투영을 갱신해 자기 교차·근접 구간에서 먼 경로로 순간 이동하지 않게 한다. 다음 게이트 너머의 진행 보상은 통과 전까지 제한한다. 새 최고 진행 거리만 보상하므로 같은 구간의 왕복으로 반복 보상을 받지 않는다. 결승은 모든 게이트 순서 통과, 경로 끝 진행도, 결승 근접을 모두 요구한다.

게이트 통과 보상과 진행 거리 보상은 분리되어 있다. 센서 도로 검사는 공간 인덱스로 후보 선분만 줄이며, 후보 안에서는 원래 선분 거리를 계산한다. 도로 경계의 판정이 전체 선분 검색과 같은지 단위 테스트로 확인한다.

### 실제 학습 비교

동일한 맵·게이트 중심·학습 시드 42, GA 24개/20세대, PPO 30회×256 rollout, horizon 1200, 평가 시드 101/202/303으로 비교했다. v1은 기존 점 접근·거리 보상이고 v2는 방향 게이트·연속 진행도 보상이다. 평가 시드 3개는 독립적인 학습 3회를 뜻하지 않으며, 정적 Racing 맵의 주행은 결정론적이다. 보상 척도가 달라 최종 보상 숫자만으로 우열을 판단하지 않는다.

| 환경/알고리즘 | v1 | v2 |
| --- | --- | --- |
| 직선 GA | 1세대부터 완주, 최종 완주율 100% | 1세대부터 완주, 최종 완주율 100% |
| 직선 PPO | 1 업데이트부터 완주, 최종 완주율 100% | 1 업데이트부터 완주, 최종 완주율 100% |
| 연속 S커브 GA | 첫 완주 17세대 / 227,109 스텝 | 첫 완주 14세대 / 175,227 스텝 |

이 GA S커브 실험에서는 첫 완주까지 약 22.8% 적은 환경 스텝을 사용했다. 모든 맵·시드·알고리즘에서 개선된다는 결론은 내리지 않는다. 특히 S커브 PPO는 이 예산에서 안정적인 완주가 확인되지 않았다.

## 변형, 선택, 복제

- 벽·장애물은 회전된 선택 경계, 네 모서리 리사이즈, 회전 핸들을 제공한다. 이동·크기 변경은 월드 좌표에 반영하고 최소 크기와 맵 경계를 제한한다. Shift 리사이즈는 비율을 유지하고 Shift 회전은 15도 단위로 스냅한다.
- 게이트는 양 끝 폭 핸들과 전진 방향 회전 핸들을 제공한다. 속성 패널에서도 위치·폭·각도·순서를 직접 입력한다.
- 장애물은 중심을 기준으로 로컬 좌표로 변환한 OBB와 원형 에이전트의 충돌을 계산한다. Racing 충돌·센서, Bounce 접촉 법선·이동·발판 반사와 렌더링 모두 회전값을 사용한다. 회전값이 없는 장애물은 0도로 해석한다.
- 선택된 핸들 → 기존 요소 → 빈 공간 생성 순으로 hit testing한다. 배치 도구를 유지한 채 기존 벽·게이트를 클릭/드래그하면 선택·이동하며 새 요소를 겹쳐 만들지 않는다. 선택 도구의 겹친 요소 순환 선택도 유지한다.
- Ctrl/Cmd+C/V/X/D는 내부 클립보드로 복사·붙여넣기·잘라내기·즉시 복제한다. 복제는 새 ID를 부여하고, 속성을 유지하며, 오프셋/맵 경계를 적용하고 새 요소를 선택한다. 게이트는 마지막 순서에 추가한다. 텍스트 입력에서는 단축키를 가로채지 않는다. 시스템 클립보드 권한을 요구하지 않는다.
- Undo/Redo는 플로팅 툴바 오른쪽 끝으로 옮겼다. 이동·리사이즈·회전은 드래그마다 하나의 기록이다. 우클릭·Space·가운데 버튼 팬과 모바일 핀치 취소도 회귀 검증했다.

## 저장 및 환경 호환성

- IndexedDB 이름·버전·object store와 기존 전체 백업 포맷을 유지했다. 저장소 삭제나 일괄 덮어쓰기는 하지 않는다.
- 맵에 `environmentVersion`이 없으면 v1이다. 기존 `Point[]`는 `gateAt()`에서 편집/표시용 기본값을 계산하며 원본을 자동으로 덮어쓰지 않는다. v1 실행은 기존 접근 판정·보상·물리를 유지하고 화면에는 점형 판정 영역을 표시한다.
- 새 환경의 스키마는 `environment:2, observation:1, action:1`이다. 모델·내장 학습 맵·평가 맵의 환경 버전을 검사해 v1 모델을 v2에서 조용히 실행하지 않는다. 추론 가중치로 새 학습을 시작할 때도 원래 환경을 선택하고, 평가는 같은 환경 버전의 맵만 제공한다. 모델에 보존된 원래 학습 맵을 직접 평가할 수 있다.
- 기존 맵을 새 게이트/회전 환경으로 바꾸려면 명시적으로 **새 환경 v2 편집본 만들기**를 사용한다. 새 맵 ID로 복사하므로 기존 저장 맵과 모델의 내장 학습 맵을 보존한다.
- GA 완전 체크포인트는 **세대 경계만** 지원한다. 세대 도중 요청하면 다음 경계까지 기다리며 UI에 대기 상태를 표시한다. 일시정지 상태가 세대 도중이면 저장 버튼을 비활성화하고 재개를 안내한다. 개체군·세대·RNG·최고 정책을 저장하며 새 파일은 `boundary:"generation"`을 기록한다.
- 이전 GA 체크포인트의 선택적 boundary 필드 부재를 허용한다. 복원 후 다음 세대 결과와 RNG/개체군이 같은지 테스트했다. 중간 개체 상태를 저장하지 않고 중간부터 완전 복원한다고 표시하지 않는다. PPO actor/critic/Adam/RNG 복원과 에피소드 경계 재개도 유지한다.
